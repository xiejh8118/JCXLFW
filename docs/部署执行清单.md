# KHMER AI 2.0 后端部署执行清单（香港轻量服务器）

> 服务器：43.129.21.17（腾讯云国际·中国香港）
> 域名：www.ccbuyhub.com
> 适用：Ubuntu 22.04 / 24.04 系统镜像，零依赖 Node 后端

---

## ⚠️ 三个最常见的坑（先做，否则后面全卡）
1. **域名必须解析到服务器 IP**，否则 HTTPS 证书申请不了。
2. **防火墙必须放通 80 / 443 / 22**，否则外部访问和证书申请都失败（轻量服务器默认只开 22）。
3. **必须能用 SSH 登录服务器**（购买时设的密码或密钥）。不会 SSH 就先去控制台确认登录方式。

---

## 第 1 步：域名解析（在域名注册商/控制台操作）
把 `www.ccbuyhub.com` 指向 `43.129.21.17`：
- 类型：`A`
- 主机记录：`www`
- 记录值：`43.129.21.17`
- TTL：默认

> 如果 `ccbuyhub.com` 这个域名已有在线网站，为避免冲突，建议改用子域名 `api.ccbuyhub.com`（同样 A 记录指向该 IP），后续把本文的 `www.ccbuyhub.com` 全部换成 `api.ccbuyhub.com` 即可。

等待几分钟，可用下面命令验证（在服务器或本地终端）：
```
ping www.ccbuyhub.com
# 应返回 43.129.21.17
```

## 第 2 步：防火墙放通端口（在云服务器控制台操作）
- 进入服务器「防火墙」/「安全组」
- 放通：`22`（SSH，一般已开）、`80`（HTTP）、`443`（HTTPS）
- 协议：TCP，来源：0.0.0.0/0

## 第 3 步：本地上传代码到服务器（在你自己电脑的终端）
项目本地路径：`d:\ZIEC\JCXLFW\cambodia-biz-travel\server`

**Git Bash（推荐）下执行：**
```bash
# 在服务器先建目录
ssh root@43.129.21.17 "mkdir -p /tmp/khmer-ai-server"

# 上传 server 目录内容
scp -r /d/ZIEC/JCXLFW/cambodia-biz-travel/server/* root@43.129.21.17:/tmp/khmer-ai-server/
```

**PowerShell 下执行：**
```powershell
ssh root@43.129.21.17 "mkdir -p /tmp/khmer-ai-server"
scp -r d:\ZIEC\JCXLFW\cambodia-biz-travel\server\* root@43.129.21.17:/tmp/khmer-ai-server/
```

## 第 4 步：登录服务器并执行部署脚本
```bash
ssh root@43.129.21.17
sudo bash /tmp/khmer-ai-server/deploy.sh
```
脚本会自动：装 Node → 部署到 `/opt/khmer-ai` → 建 systemd 服务 → 装 Nginx + Certbot → 配反代。

## 第 5 步：申请 HTTPS 证书（在服务器终端）
```bash
sudo certbot --nginx -d www.ccbuyhub.com
```
- 按提示填邮箱、同意条款。
- 成功后 Nginx 自动加 443 并跳转 HTTPS。
- 验证：`curl https://www.ccbuyhub.com/api/health` 应返回 JSON。

> 若证书申请报"域名无法访问"，回第 1、2 步检查解析与防火墙。

## 第 6 步：小程序后台加白名单（在微信公众平台操作）
- 登录 https://mp.weixin.qq.com → 开发 → 开发设置 → 服务器域名
- **request 合法域名** 添加：`https://www.ccbuyhub.com`
- 保存（需稍等几分钟生效）

## 第 7 步：前端地址（已改好，确认即可）
`miniprogram/utils/api.js` 的 `BACKEND_BASE` 已改为 `https://www.ccbuyhub.com`，无需再改。

## 第 8 步：上传小程序并提交审核
- 微信开发者工具「上传」→ 填版本号（如 1.1.3）→ 提交审核。
- 后台补【深度合成-AI问答】类目（参赛/合规必须）。
- 等待审核。

## 失败自查
| 现象 | 原因 | 处理 |
|------|------|------|
| certbot 报无法访问域名 | 解析未生效/防火墙未放 80 | 回第1、2步 |
| 小程序 request 失败 | 白名单未加 / 域名未生效 | 第6步 |
| 服务起不来 | Node 装错 / 端口被占 | `systemctl status khmer-ai --no-pager` 看日志 |
| 显示"服务器失败" | 仍是占位符或后端没跑 | 确认 BACKEND_BASE 与 /api/health 通 |

## 常用运维命令（在服务器）
```bash
sudo systemctl status khmer-ai      # 看服务状态
sudo systemctl restart khmer-ai     # 重启
sudo journalctl -u khmer-ai -n 50   # 看日志
sudo nginx -t && sudo systemctl reload nginx  # 改 Nginx 后重载
```
