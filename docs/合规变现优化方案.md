# 柬企海外商旅服务 · 合规变现优化方案

> 基于原始方案（公众号→小程序→企微→ABA Pay）的合规性优化和加速变现策略

---

## 一、原方案诊断

### 4 个关键风险

| # | 问题 | 风险 | 后果 |
|---|------|------|------|
| 1 | 品牌矩阵混乱：公众号"柬税笔记"、服务号"柬税观"、小程序"柬税笔记"+"柬企海外商旅服务" | 🔴 高 | 用户认知断裂；"商旅服务"会触发旅游类目审核 |
| 2 | ABA Pay 写在小程序里："选择→ABA Pay支付" | 🔴 高 | 小程序代码直接跳外部支付 = "绕过微信支付"，审核必拒 |
| 3 | "自测高风险→推荐服务"营销感强 | 🟡 中 | 用户做完自测发现高风险被推服务 = 营销套路，降低信任 |
| 4 | "每月自动续费"在小程序内 | 🟡 中 | 小程序不能做自动续费（需特殊类目），审核会拒 |

### 核心认知

微信审核只看**小程序代码里有什么功能**：
- 有支付按钮/下单流程/预订系统 → 需要对应类目资质
- 只有信息展示+工具+客服按钮 → 无需特殊资质，审核必过
- 客服会话里聊什么、外部怎么付款 → 微信管不着

## 二、优化方案：三层合规架构

### 第一层：小程序内（审核必过）

**只放四类东西：**
1. **免费工具**：VAT/WHT/薪资税计算器、汇率换算、佛历转换
2. **信息展示**：酒店介绍、签证攻略、合规指南（无价格、无下单）
3. **客服按钮**：`<button open-type="contact">` 唤起微信原生客服
4. **邀请码解锁**：输入码 → 展示会员内容（代码里无支付逻辑）

### 第二层：微信生态内但代码外

1. **公众号文章**：SEO获客（"柬埔寨增值税""柬埔寨代扣税"等长尾词）
2. **客服会话**：报价、发材料清单、发ABA Pay链接
3. **企业微信**：1v1顾问诊断、发支付链接、发邀请码、社群运营

### 第三层：完全外部

1. **ABA Pay H5支付页**：独立网站，不挂在小程序下
2. **银行转账**：对公账户
3. **线下签约**：纸质合同

## 三、4 项关键优化

### 优化 1：品牌统一

| 触点 | 原名称 | 建议名称 |
|------|--------|----------|
| 公众号 | 柬税笔记 | 柬税笔记（保留） |
| 服务号 | 柬税观 | 柬税笔记Pro（或保留） |
| 小程序 | 柬企海外商旅服务 | 柬税笔记（或柬企财税工具） |
| 小程序定位 | 商旅服务 | 商务信息查询与税务工具 |

**关键**：小程序名称里不要出现"商旅""旅行""酒店"字样，避免触发旅游类目审核。

### 优化 2：ABA Pay 只走企微

| 场景 | ❌ 不能做 | ✅ 可以做 |
|------|----------|----------|
| 小程序代码 | `wx.navigateTo({ url: 'abapay.com/pay' })` | 无任何支付跳转代码 |
| 客服会话 | — | 客服发ABA Pay链接，用户点击跳浏览器 |
| 企业微信 | — | 顾问发支付链接到企微聊天 |
| H5支付页 | 挂在小程序域名下 | 独立域名，与小程序无关 |

### 优化 3：体检替代自测

| 原方案 | 优化后 |
|--------|--------|
| 企业合规自测 → 结果高风险 → 推荐服务 | 合规体检 → 生成体检报告 → 底部「获取专业解读」→ 唤起客服 |
| 营销感强，用户抗拒 | 工具属性，用户主动想了解 |
| 自测=营销入口 | 体检=专业工具+自然引流 |

### 优化 4：邀请码解锁会员

**流程：**
1. 用户在企微完成ABA Pay支付
2. 企微顾问发送专属邀请码
3. 用户在小程序「会员中心」输入邀请码
4. 小程序验证通过 → 解锁会员专享内容

**为什么合规：**
- 小程序代码里没有任何支付逻辑
- 邀请码验证只是字符串比对，不是交易
- 会员内容是信息展示，不是虚拟商品
- "付费"发生在企微（外部），"使用"发生在小程序（内部）

### 完整变现路径

```
用户搜索"柬埔寨增值税"
  ↓
公众号文章获客 → 关注公众号
  ↓
公众号菜单 → 进入小程序
  ↓
免费算税工具（养成习惯）
  ↓
合规体检 → 生成报告（A/B/C/D评级）
  ↓
报告底部「获取专业解读」→ 唤起客服
  ↓
客服识别来源（session-from=checkup_report）
  ↓
企微顾问1v1诊断 → 推荐税务合规托管
  ↓
企微发ABA Pay链接 → 用户在H5支付 $500/月
  ↓
企微发邀请码 → 用户在小程序输入
  ↓
小程序解锁会员内容（案例库/模板/服务进度）
  ↓
每月持续使用 + 服务进度透明 → 复购
```

## 六、合规检查清单

提交审核前逐项检查：

- [ ] 小程序代码里搜索 `requestPayment` → 必须为 0 处
- [ ] 小程序代码里搜索 `pay` / `支付` / `下单` / `预订` → 不能出现在按钮文案中
- [ ] 所有价格标注为"参考价""起价"
- [ ] 所有交易按钮文案为"咨询客服""了解详情""获取专业解读"
- [ ] `app.json` 服务类目选「工具→信息查询」或「商业服务」
- [ ] 小程序描述不含"酒店预订""机票购买""签证办理"
- [ ] 客服功能已在微信公众平台配置
- [ ] 邀请码验证逻辑不涉及任何金额数字
