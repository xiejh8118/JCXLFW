# KHMER AI 事业化长远规划

> 定位：把"2026 微信小程序大赛参赛作品 KHMER AI 2.0"升级为**中鼎在柬埔寨可长期运营的数字业务底座**。
> 核心命题：就算没中奖，这套系统也能作为公司日常运营工具 + 对外收费服务持续产生价值。
> 适用对象：阿聪（定方向/客户/资源）+ 阿智（技术规划与落地）

---

## 一、一句话定位

**用 AI 把中鼎在柬埔寨现有的酒店 / 物业 / 地产 / 旅游业务线上化、智能化，并横向向其他在柬中企输出"企业落地服务 + 供应链撮合"。**

对内：降本增效，自己先用起来。
对外：可收费，别人也能用。

---

## 二、为什么能做成"事业"而不是"参赛 demo"

| 维度 | 现状（已经是资产） | 转化为事业的价值 |
|------|------|------|
| 业务底盘 | 中鼎国际柬埔寨分公司、酒店管理、泰兴地产、物业管理 | 真实业务场景，系统不是空壳 |
| 资质 | 旅游证 + 营业执照（Hotel 资质） | 可合规上线"酒店/旅游"类目，能对外接单 |
| 客户 | 在柬中企 + 华人客群 | 现成需求，不缺种子用户 |
| 痛点 | 在柬中企落地难、信息散、语言隔阂 | AI 多语言助手正好解决信息不对称 |
| 技术 | 已跑通 AI/匹配/需求单闭环 | 半成品已成型，加业务即上线 |

结论：**底盘是真实的，小程序只是把底盘搬到线上 + 加 AI 杠杆。**

## 三、三层业务架构（由己及人，逐级放大）

### L1 自营业务数字化（先跑通，自己用）
把中鼎已有业务搬上线，不依赖外部：
- 酒店：预订 / 入住 / 客需
- 物业：报修 / 工单 / 巡检
- 地产：租赁 / 出售展示
- 旅游：线路 / 接待

目标：中鼎内部先用，省人省事，沉淀数据。

### L2 企业服务撮合（对外收佣金 / 服务费）
把"在柬中企落地"做成撮合市场：
- 需求单闭环 → 企业落地服务（注册 / 财税 / 法务 / 签证 / 人力）
- 供应链匹配（建材 / 食材 / 设备 / 物流 / 办公）
- 引入第三方服务商入驻，成交抽佣

目标：从"成本中心"变"收入中心"。

### L3 平台与数据（规模化后）
- 在柬中企服务市场（类"柬埔寨中企黄页 + 撮合"）
- 企业会员订阅（优先匹配、专属 AI、月度报告）
- 行业数据洞察报告（对外售卖 / 招商用）

目标：形成网络效应与数据壁垒。

---

## 四、盈利模式（不中奖也能赚钱）

1. **自营业务线上转化**：酒店 / 旅游 / 地产 / 物业直接成交，本来就要花的钱走系统。
2. **撮合佣金**：供应链 / 企业服务成交抽佣（3%~10%，按品类定）。
3. **会员订阅**：企业会员月费（优先匹配、专属 AI、深度报告）。
4. **增值服务**：合规体检报告、深度咨询、代办落地。
5. **服务商入驻 / 展示**：第三方服务商付费展示位。

> 优先级建议：先做 1（自有业务），跑顺后做 2+4（撮合与代办），最后做 3+5（会员与平台）。

## 五、产品路线图（分阶段，对老板可汇报）

| 阶段 | 时间 | 目标 | 关键动作 | 验收 |
|------|------|------|------|------|
| **阶段 0** | 现在 | 参赛 + 过审 | 轻量服务器部署、去引流、AI 标识、类目补全 | 审核通过、闭环跑通 |
| **阶段 1** | 0–3 月 | 自营上线 | 真实业务接入（酒店/物业/地产/旅游）、AI 接真实模型 | 员工日常在用 |
| **阶段 2** | 3–6 月 | 撮合对外 | 开放企业服务撮合、引第三方服务商、收佣金 | 首笔撮合成交 |
| **阶段 3** | 6–12 月 | 平台化 | 会员体系、数据报告、服务商市场 | 稳定现金流 |

> 不中奖不影响 0→1→2→3 推进，大赛只是加速器。

## 六、技术演进路线（跟着业务走，不超前）

| 阶段 | 架构 | 说明 |
|------|------|------|
| 现在 | 香港轻量服务器 + 零依赖 Node + JSON 文件 | 快、省、够用，先跑通 |
| 成长 | 换 PostgreSQL + 进程守护 + 备份 + 监控 | 业务有量后数据可靠 |
| 规模 | 容器化 / 多实例 / 对象存储 / 缓存 | 撮合和会员起量后 |
| AI | 模板降级 → 接微信 AI 生态 / 合规大模型 API | 注意海外数据合规 |

原则：**业务没量不堆架构，避免烧钱**。

## 七、合规与风险（海外主体红线，长期适用）

1. **服务器位置**：必须在香港 / 新加坡（免备案）。境内服务器对境外主体需 ICP 备案，几乎办不了。
2. **小程序域名**：request 合法域名仅支持 https，需加入白名单。
3. **类目**：AI 问答需【深度合成-AI问答】；酒店需【旅游-酒店服务】。类目不全 = 反复驳回。
4. **引流红线**：小程序内不可强制引导到外部渠道（客服 / 企微 / 外部支付）。支付走小程序内或纯展示。
5. **数据合规**：用户数据存储与跨境需符合柬埔寨本地 + 中国相关规定，敏感数据本地化。
6. **支付**：境外主体小程序内支付受限，建议成交走自有业务系统 / 境外支付（ABA Pay 等），小程序内只做展示与需求收集。

## 八、组织与投入（最小可行）

- **最小团队**：1 业务/运营（阿聪或指派）+ 1 全栈/前端 + 外包 AI/设计。
- **阿聪职责**：定方向、给客户、拍板变现模式、对外谈服务商。
- **阿智职责**：技术规划、落地、部署、文档、迭代。
- **投入节奏**：先轻量跑通（38 元/月服务器），验证后再加机器、加人、加业务。
