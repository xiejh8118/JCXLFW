## 二、各账号角色定位

### 服务号「柬税观」— 流量入口

**定位**：柬埔寨华商的税务知识库，通过内容吸引精准客户

**核心动作**：

1. **内容矩阵**（每周2篇）
   - 税务干货：「柬埔寨VAT怎么算」「WHT扣缴实务」「薪资税累进计算」
   - 商情速递：每月1篇政策变动/行业动态
   - 客户案例：每月1篇真实服务案例（脱敏）

2. **菜单栏配置**
   ```
   一级菜单        二级菜单         跳转
   ─────────────────────────────────
   税务工具   →   VAT计算器       小程序
              →   合规体检         小程序
              →   薪资税计算       小程序
   商务服务   →   财税代办         小程序服务页
              →   签证办理         小程序服务页
              →   酒店预订         小程序服务页
   关于我们   →   联系客服         唤起客服
              →   会员中心         小程序会员页
   ```

3. **模板消息**（认证后可用）
   - 体检报告推送：「您的合规评级为B级，点击查看详情」
   - 服务进度通知：「您的签证申请已进入第二阶段」
   - 续费提醒：「您的财税代办服务将于X天后到期」

4. **搜索SEO**
   - 文章标题埋长尾词：「柬埔寨VAT申报流程」「柬埔寨工作签证费用」
   - 微信搜一搜是精准流量入口，来搜的都是有真实需求的

### 小程序「柬企海外商旅服务」— 工具+转化

**定位**：免费税务工具引流，体检制造需求，客服完成转化

**页面结构**（当前已实现）：

| Tab | 页面 | 作用 |
|-----|------|------|
| 首页 | index | 工具入口 + 今日汇率 + 快捷服务 |
| 税务 | tax | VAT/WHT/薪资税计算器 |
| 合规 | compliance | 法规查询 + 合规检查清单 |
| 我的 | profile | 会员中心 + 服务进度 |

**新增页面**：

| 页面 | 作用 | 转化触点 |
|------|------|----------|
| checkup | 6题合规体检→ABCD评级 | 底部「获取专业解读」→客服 |
| services | 三条业务线展示 | 每个卡片含客服按钮 |
| member | 会员卡+邀请码+进度看板 | 续费/升级→客服 |

**转化设计**：
- 每个工具计算结果底部 → 「结果仅供参考，点击获取专业解读」→ 客服
- 体检报告页 → 「您的评级为B级，存在X项风险，建议咨询专业人士」→ 客服
- 服务展示页 → 不做交易，只展示信息+「咨询详情」→ 客服

### 企微 — 成交闭环

**定位**：1v1专业服务，报价收款售后全在这里

**成交流程**：
1. 客服会话确认需求类型（财税/签证/酒店）
2. 发送企微名片，客户添加企微
3. 企微1v1详细沟通 → 报价
4. 发送ABA Pay支付链接（H5页面）
5. 收款确认 → 开始服务
6. 服务进度通过模板消息同步
7. 服务完成 → 邀请评价 → 推荐会员/续费

### Week 3：体检引爆（Day 15-21）

**核心活动**：「柬埔寨企业合规免费体检」

**活动设计**：
1. 服务号推文：「你的企业在柬埔寨合规吗？6题自测」
2. 文章内嵌小程序卡片 → 体检页面
3. 用户完成6题 → 生成ABCD评级报告
4. 报告页底部：「您的评级为X级，存在N项风险，点击获取专业解读」→ 客服
5. 客服承接 → 了解企业情况 → 发企微名片

**6道体检题**（已实现）：
1. 是否按月申报VAT？
2. 是否了解WHT扣缴义务？
3. 外籍员工是否办理工作证？
4. 是否做CIFRS转换报表？
5. 专利税是否按时缴纳？
6. 是否有税务筹划方案？

**评级标准**：
- A级（6/6）：合规良好 → 推荐年度审计服务
- B级（4-5/6）：存在风险 → 推荐税务筹划
- C级（2-3/6）：风险较高 → 推荐月度代办
- D级（0-1/6）：严重不合规 → 紧急咨询

**客服话术SOP**：
```
用户唤起客服后：
1. 「您好，我是柬税观专业顾问，看到您刚完成了合规体检」
2. 「您的评级是X级，主要风险在[具体项]，请问贵司目前在柬埔寨经营多久了？」
3. 「这种情况我们建议[对应服务]，我可以发您一份详细方案，方便加一下企业微信吗？」
4. 发送企微名片
```

**验收标准**：体检完成 > 100人次，客服咨询 > 25人，企微添加 > 15人
